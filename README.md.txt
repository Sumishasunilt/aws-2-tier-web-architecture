# AWS 2-Tier Web Architecture

## Project Overview

Designed and implemented a scalable 2-tier web architecture using AWS services.

- Configured load balancing using Elastic Load Balancer
- Configured Auto Scaling for EC2 instances
- Implemented secure database connectivity using Amazon RDS
- Configured monitoring and alerting using Amazon CloudWatch

## AWS Services Used

- Amazon EC2
- Elastic Load Balancing
- Auto Scaling
- Amazon RDS
- Amazon CloudWatch
- Amazon VPC
- IAM
